# Automation Policy and Labels

- `agent-generated`: the substantive change was generated by an identified agent.
- `agent-assisted`: automation assisted a human-authored change.
- `human-reviewed`: a named human reviewed evidence and output.
- `needs-verification`: required verification remains incomplete.
- `provenance-complete`: required provenance fields and checks pass.
- `upstream-candidate`: a reviewed mapping may benefit an upstream project.
- `downstream-integration`: a confirmed integration report or example.

Automated changes must disclose the agent/tool, version, operator, task, source
inputs, transformation, validation, human-review state, and reproduction steps.
They must be narrow and rate-limited. Labels describe process state, not truth.
