# Methodology

Claims cite primary specifications. Sources, records, relationships,
disagreements, summaries, and transformations remain separate. Summaries are
interfaces to evidence, never evidence for later summaries.

Capability labels are descriptive: `primary`, `supported`, `indirect`, or
`out-of-scope`. Trust dimensions are independent and never averaged.

Canonical JSON is validated before deterministic generation. Corrections update
dependent outputs and preserve supersession history. See the
[complete methodology on GitHub](https://github.com/55515-code/open-provenance-knowledge/blob/main/METHODOLOGY.md).
